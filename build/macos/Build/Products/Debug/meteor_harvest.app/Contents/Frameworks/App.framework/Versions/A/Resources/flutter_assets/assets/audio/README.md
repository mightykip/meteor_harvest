# Audio Assets Directory

This directory contains the audio resources (sound effects and background music) for **Meteor Harvest**. 

## Audio Assets Checklist & Prompts

You can use AI music generators (e.g., Suno, Udio) or SFX generators (e.g., ElevenLabs, ElevenLabs Reader, sfxr, Chiptone, Stable Audio) to produce these files.

### 1. Background Music

*   **`music_space_arcade_loop.mp3`**
    *   **Description:** Upbeat, retro-modern sci-fi background track. Loopable.
    *   **Prompt for Generation:**
        ```text
        Create a short seamless looping background music track for a polished mobile arcade space game. Style: upbeat synthwave, energetic but not distracting, sci-fi adventure mood, 90–110 BPM, clean loop, 30–60 seconds.
        ```
